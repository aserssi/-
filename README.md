# 校圈 Campus Circle

**面向本校学生的校园社交与互助平台。**

校圈希望围绕学生的校园生活，把同校交流、学习与生活求助、经验分享和失物招领组织起来，让需要帮助的人更容易找到合适的同学，也让有用的回答能够被后来的同学再次找到。

> 当前阶段：选题与初步调研准备（v0.1 草稿）。本仓库已整理选题原因、调研框架、访谈提纲和问卷草案；尚未开展真人访谈或收集问卷。文中的痛点与功能方向均为待验证假设，不代表已经取得的调研结论。

## 为什么选择“校圈”

1. **贴近可以实际接触的用户。** 同校学生的交流与求助是明确的研究场景，团队能够通过真实访谈了解需求，并在后续邀请同学试用。
2. **研究“找到人、找到信息、解决问题”的完整过程。** 重点关注跨班级交流、经验查找和求助跟进，评估现有沟通渠道是否存在尚未解决的问题。
3. **兼顾用户体验与社区管理。** 除学生之外，还需要考虑版主、管理人员和维护人员，适合练习需求分析、权限设计、内容治理与软件测试。
4. **范围可以逐步收敛。** 初期围绕校园社交与互助验证价值，再决定具体功能，避免将项目扩大为覆盖所有校园业务的综合平台。

详细论证见 [选题说明](docs/01-topic-selection.md)。

## 初步研究范围

| 方向 | 要了解的实际问题 | 候选场景 |
| --- | --- | --- |
| 校园社交 | 同学通过什么方式找到有共同话题的人？在哪一步遇到困难？ | 兴趣交流、学习搭子、校园经验分享 |
| 校园互助 | 学生怎样发布问题、获得有效回应并确认解决？ | 学习求助、生活咨询、失物招领 |
| 信息查找 | 以前讨论过的问题能否被再次找到？ | 话题分类、关键词搜索、已解决经验沉淀 |
| 社区治理 | 怎样保护个人信息、处理不当内容并解释处理结果？ | 身份可信度、隐私设置、举报与反馈 |

以上是调研方向，尚未确认为功能需求。首期暂不纳入二手交易与支付、教务管理、复杂推荐算法或大型活动管理。
