# 校圈调研工具包

版本：v0.1 草稿 · 更新日期：2026-11-20

以下内容用于真实调研的准备。题目需先试访、试填再修订；空白记录不是调研证据。

## 1. 访谈开场说明

我们正在为软件工程课程研究校园社交与互助的使用情境，希望了解你实际经历过的问题。本次交流约 15–20 分钟，参与完全自愿，可以跳过问题或随时结束。记录仅用于课程分析，公开材料会做匿名化处理，不记录姓名、学号或联系方式。若需要录音或引用原话，会另外征得你的同意。

先说明记录用途与保存方式，再确认是否同意参与；未获同意则不开展记录。

## 2. 学生访谈提纲（8 个主问题）

1. 最近一次想认识同校同伴、交流校园经验或请别人帮忙，是什么事情？请从最开始讲起。
2. 当时通过哪些渠道找人或信息？为什么先选这个渠道，又为什么换到另一个渠道？
3. 整个过程中哪一步最顺利、哪一步最麻烦？能否讲一个具体片段？
4. 最后有没有获得有效回应或解决问题？你怎样判断已经结束，是否还需要追问？
5. 如果后来要找回那次回答或经验，你会怎样找？最近是否真的做过这件事？
6. 你最近有没有帮助过别人或分享过经验？是什么促使你回应，什么情况让你不想继续？
7. 有没有想发言但最后没发、退出某个群组或停止求助的经历？为什么？对身份与个人信息公开有什么顾虑？
8. 现有方式有哪些地方已经很好？如果出现新的校园交流工具，你会在什么情况下尝试，又会因为什么不愿使用？

追问以“发生了什么”“后来怎样”“能否举例”为主，避免问“你是不是也觉得消息太多”“如果有校圈你肯定会用吧”等引导性问题。

## 3. 管理相关人员补充提纲

1. 目前由谁管理交流渠道，日常最花时间的工作是什么？
2. 最近一次不当信息、重复求助或争议是怎样处理的？有哪些依据和困难？
3. 举报、通知当事人、申诉或结果说明目前如何进行？
4. 哪些个人信息不应收集或公开？学生身份可以通过什么合适的方式确认？
5. 如果开展课程试点，谁可以提供管理支持？内容审核、维护时间和外部服务费用有哪些约束？

不要把受访者的一次个人意见直接当作学校正式政策；需要政策依据时，另行核实有权限的管理方。

## 4. 学生问卷草案（12 题，目标约 5 分钟）

**问卷说明：** 本问卷用于课程项目的前期研究，匿名、自愿、不收集姓名、学号、手机或微信号。回答可以跳过。参与者仅填写自己的经历；不适用时请选择相应选项。正式发放前补充负责人、使用范围与数据保存安排。

| 题号 | 题目 | 题型与选项建议 |
| --- | --- | --- |
| Q1 | 你是否目前在本校就读？ | 单选：是／否／不愿回答。选择“否”结束学生问卷，不并入本校学生统计；不愿回答者单独列示，不直接归入本校样本 |
| Q2 | 你目前处于哪个学习阶段？ | 单选：本科一/二/三/四年级／研究生／其他／不愿回答 |
| Q3 | 过去一个月，你参与过哪些校园交流或互助？ | 多选：找学习或兴趣同伴／学习求助／生活咨询／经验分享／失物招领／其他／没有参与。“没有参与”与其他项互斥 |
| Q4 | 过去一个月，你主要通过哪些渠道参与这些活动？ | 多选：班级或年级群／兴趣或学习群／校园信息账号／校园社区或论坛／线下熟人／其他／不适用。不适用与其他项互斥 |
| Q5 | 过去一个月，你大约发起过多少次相关交流或求助？ | 单选：0 次／1–2 次／3–5 次／6 次及以上／记不清 |
| Q6 | 最近一次发起交流或求助，最后是什么结果？ | 单选：达到目的／部分达到／没有达到／仍在进行／没有相关经历 |
| Q7 | 最近一次寻找校园信息或交流对象时，你大约花了多久找到合适结果？ | 单选：5 分钟内／超过 5 分钟且不超过 30 分钟／超过 30 分钟／未找到／记不清或不适用。仅为自报估计，不当作实际性能测量 |
| Q8 | 在这些经历中，你遇到过哪些困难？ | 多选：不知道去哪里问／找不到合适的人／历史信息难找／无人回应／信息真假难判断／结果难跟进／担心个人信息暴露／其他／没有明显困难。最后一项互斥 |
| Q9 | 如果只能优先改善两项，你会选择什么？ | 最多选两项：找同伴／查找既有经验／获得有效回答／跟进求助结果／减少不当内容／保护隐私／其他／暂无需要。暂无需要与其他项互斥 |
| Q10 | 当你愿意回应他人时，哪些因素会影响决定？ | 多选：问题描述清楚／自己熟悉该问题／有时间／对方身份可信／能看到后续反馈／其他／通常不回应。通常不回应与其他项互斥 |
| Q11 | 为便于校园交流，你愿意公开哪些信息？ | 多选：昵称／兴趣标签／学习阶段／院系（自愿）／仅显示已验证的本校身份／都不愿公开／其他。都不愿公开与其他项互斥；此题只问态度，不收集这些信息 |
| Q12 | 现有方式最值得保留的是什么？什么情况下你会愿意或不愿意尝试新平台？ | 开放题，可不填。提醒不要填写姓名、学号、联系方式或可识别他人的细节 |

实施说明：

- Q3、Q5 均显示没有参与/发起经历的答卷仍可用于研究潜在用户与阻碍因素，不自动判为无效。
- 对没有经历的用户，Q6/Q7 提供不适用选项，不强迫其虚构结果。
- 同一题的互斥选项应在问卷工具中设置；开放题无需强制作答。
- 问卷发布前先检查平台是否默认收集姓名、手机号、账号或其他不必要的可识别信息。
- 先记录有效答卷规则和样本来源；不根据回答是否支持项目决定是否保留。

## 5. 访谈记录模板

复制本节建立单独记录。所有字段均须根据真实访谈填写。

```text
证据编号：INT-___
访谈日期与时长：待记录
访谈人 / 记录人：待填写
匿名受访者描述：例如“低年级学生，主要浏览，很少发言”（真实信息）
同意参与及记录方式：待确认
录音/原话引用授权：待确认；未获授权则不录音/不公开引用

最近一次具体经历：
现有渠道与实际步骤：
顺利之处：
遇到的困难与影响：
采取的替代办法：
最后结果：
受访者原话（经允许）：
反例/意外发现/被否定的设想：
记录者的解释（与原话分开）：
对应假设 H01–H06：
还需核实的问题：
原始记录保存位置与访问范围（不公开敏感链接）：
脱敏检查人及日期：
```

## 6. 调研发现记录模板

| 字段 | 待填写内容 |
| --- | --- |
| 发现编号 | F-___ |
| 发现描述 | 谁在什么场景遇到什么问题，带来什么影响 |
| 支持证据 | INT/OBS/SUR 编号及具体条目 |
| 相反或限制性证据 | 不支持该发现的样本、场景和其他解释 |
| 当前判断 | 支持／部分支持／不支持／证据不足 |
| 样本与局限 | 来源、数量、覆盖面、可能偏差 |
| 处理建议 | 保留方向／进一步验证／暂缓／放弃 |
| 人工确认 | 确认人、日期、讨论记录链接；未确认则标“待评审” |

没有证据时写“证据不足”，不补写“多数同学认为”“调研显示”等结论。后续形成用户故事时引用真实发现编号。
